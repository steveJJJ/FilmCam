# `pro_unlock` 商品页 — 可直接复制的文案卡

> 对应截图：Play Console「创建一次性商品」→ 产品说明区。
> 字段限制（截图实测）：**名称 ≤ 55 字符**、**说明 ≤ 200 字符**；标签、图标均可选，留空即可。
> 默认语言是 **英语（美国）- en-US**（截图「默认 - 英语（美国） - en-US / 管理翻译」）。

---

## 1. 先改「名称」（现在填的中文长串要换掉）

当前填的是 `工程模式（Pro）/ 一次性解锁、永久可用、非订阅`（25/55）。
问题：① 默认语言是 en-US，海外用户会看到中文；② 名称会显示在**购物车**里，「一次性解锁/非订阅」属于说明内容，不该塞进名称。

**名称（en-US）→ 填：**

```
Engineering Mode (Pro)
```

（22/55 字符）

---

## 2. 「说明」必填，红框「请输入说明」就是卡在这里

**说明（en-US）→ 填：**（183/200 字符）

```
Unlocks Engineering Mode: slow shutter, output style, per-film development and colour controls. One-time purchase, permanent; restore with the same Google Account. Not a subscription.
```

---

## 3. 加中文（建议，App 本身有中文界面）

点名称上方的 **「管理翻译」** → 勾选 **简体中文 (zh-CN)** → 应用，然后分别切到中文填：

**名称（zh-CN）：**

```
工程模式（Pro）
```

**说明（zh-CN）：**

```
一次性解锁工程模式专家面板：慢门档位与触发机制、输出风格（印相 / Frontier / Noritsu）、按胶卷分组的冲洗参数、色彩微调与镜头柔度。一次购买、永久可用；重装或换机后用同一 Google 账号可恢复。非订阅，购买由 Google Play 处理。
```

> 不想加翻译也能保存：直接在 en-US 下填中文名称+中文说明即可，只是海外用户会看到中文。
> ⚠️ 商品元数据按 Play 政策必须**准确、不误导**：工程模式还有「关于页版本号连点 10 次」的免费彩蛋入口，所以说明里**不要**写「唯一解锁方式 / 仅购买可用」这类绝对化措辞。

## 5. 点「继续」之后（第 2 步逐字段见 `PLAY_PRODUCT_STEP2.md`）

1. **税务、法规遵循和计划**：按页面引导完成；内容属数字内容，面向欧盟注意撤回权设置。
2. **购买选项**：ID 填 `buy`、类型保持「购买」、只建 1 个；高级选项不启用数量上限。
   ⚠️ **更正**：不用找「向后兼容 / legacy compatible」——首个 Buy 购买选项由 Play 自动标记，且本项目 billing 9.1.0 走新模型，只有 PBL 7 或更旧才需要手动标。
3. **价格**：点右上 **Set prices → 批量修改价格** → 全选地区 → 填 `2.99` / 币种 **USD** → 应用 → 继续。
4. **点「保存」→「启用」**（中文界面按钮叫「启用」，英文 Activate）—— ⚠️ 只保存不启用，用户点购买什么都不弹。

完整逐字段说明见 `PLAY_PRICING_FILL_GUIDE.md` 第 4 节；第 2 步界面见 `PLAY_PRODUCT_STEP2.md`。
